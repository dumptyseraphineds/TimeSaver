# TimeSaver: Task Manager & Pomodoro

HIIIIII! Welcome to **Time Saver**, a desktop application developed entirely in Java, which combines task management with the Pomodoro Technique to maximise productivity.

## Key Features
- **Task Management:** Easily add, edit, delete and mark tasks as completed.
- **Pomodoro Timer:** A built-in timer with breaks to help you study or work without distractions.
- **User System:** Registration and login system. Each user has their own calendar and saved settings!
- **Graphical User Interface (GUI):** User-friendly windows and intuitive design created with NetBeans and Java Swing.
  
## How to use TimeSaver?

It’s super easy and intuitive! Just follow these simple steps:

1. **Start your journey:** When you open the app, you can sign up as a new user or log in if you already have an account. Your information and task calendar are completely private and saved just for you! 
2. **The Main Menu:** From here, you can navigate to the three main tools:
   - **Task Management:** Add your to-do items, edit them, tick them off when you’ve finished, or delete them to keep your day super organised. 
   - **Pomodoro Timer:** Head to this section when you need total concentration. Start the 25-minute timer for your study session and give it your all! 
   - **User Settings:** Edit your account information.
3. **Save your progress!** When you finish your programming or study session, make sure to log out using the relevant button so that the system saves all your tasks and settings to your local files.
